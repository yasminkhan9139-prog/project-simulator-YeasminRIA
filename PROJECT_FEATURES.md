

\# Implemented Features



\## Student Information



\- Student ID is stored for every student.

\- Student name is stored for every student.

\- Student age is stored for every student.

\- Student CGPA is stored for every student.

\- Student department is stored for every student.

\- Student email is stored for every student.

\- Student phone number is stored for every student.

\- Student address is stored for every student.

\- Student gender is stored for every student.

\- Student semester is stored for every student.

\- Student credit hours are stored for every student.

\- Student status is stored for every student.



\## Field Improvements



\- Student name capacity increased from 50 to 100 characters.

\- Student address capacity increased from 100 to 200 characters.

\- Student phone number capacity increased from 20 to 25 characters.

\- Student ID field renamed from `id` to `studentId`.

\- Student name field renamed from `name` to `studentName`.## Student Status
